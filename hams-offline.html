Hams

Chat with the devices around you by sound. No internet, no accounts.

  1. Messages travel as tones most adults cannot hear.
  2. Everyone in the same room with Hams open can join.
  3. Groups with a shared code keep messages private.

Joining turns on the microphone. Hams listens only while this page is open, and nothing leaves your device except the sound it plays.

Made by Murtadha

New group

Messages in a group are encrypted with its code. Only devices with the same code can read them; everyone else ignores them.

Share the code in person. Longer than 8 characters is harder to guess.

Settings

Your name

Device number . A fixed random number that tells your messages apart from others with the same name.

Groups

Each group is a shared code. Removing one hides its messages on this device.

Use it offline

On a laptop with no internet at all: download Hams as a single file and open it in Chrome, Edge or Firefox. Pass it on by USB, Bluetooth or any chat app; it needs nothing else.
